# CodeAlpha_Educational-Performance

# Educational Performance & Resource Allocation Dashboard

# Project Overview

This project presents an interactive Educational Performance & Resource Allocation dashboard developed using Microsoft Power BI.

# Objectives

- Analyze student academic performance
- Evaluate student attendance and GPA
- Compare academic performance across courses and departments
- Analyze educational resource utilization
- Identify resource gaps and capacity requirements
- Analyze student enrollment across courses
- Support data-driven education management decisions
